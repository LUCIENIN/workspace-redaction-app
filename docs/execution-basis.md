# 执行依据与边界

Workspace Veil 的“执行依据”是一组工程与授权约束，不是法律意见，也不是自动合规证书。

1. **明确授权**：只处理用户明确放入范围的账号、仓库、路径和动作。
2. **数据最小化**：先缩小公开集，再谈脱敏；不需要公开的文件不进入导出物。
3. **保留原始证据**：默认不覆盖原文件，只向新的隔离目录写入处理结果。
4. **最小权限**：本地扫描不需要网络和凭据；CI 只请求 `contents: read`。
5. **隐私安全报告**：报告仅记录文件、类别、严重性和数量，不保存命中原文片段。
6. **独立验证**：本地没有命中、GitHub Actions 通过和远程可读是三类不同证据，不能互相代替。
7. **结论边界**：“未命中”只能证明已配置规则在可读文本中没有找到相应模式。

## 需要额外工具的内容

- 图片的 EXIF 与可见画面。
- PDF 的隐藏层、表单、批注与附件。
- Office 文档的修订记录、作者元数据与隐藏工作表。
- 数据库、压缩包、音视频和二进制模型文件。
- 只有业务人员才能识别的商业机密与语义泄露。

## 真实凭据已进入 Git 历史时

先在对应服务中撤销或轮换凭据，再评估是否需要清理 Git 历史。仅删除当前分支的文件不会使旧凭据失效。
